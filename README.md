# Python Lab

Настольное приложение для Windows: учит программировать на Python с нуля.
Слева идёт урок и разговор с учителем, справа редактор кода и консоль.

Рассчитано на человека, который никогда не видел кода.

---

## Как запустить

**Из исходников** (для разработки):

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py
```

**Собранное приложение**: запустить `PythonLab.exe` из папки сборки.
Python на машине не нужен.

---

## Ключ OpenAI

Без ключа работают уроки, задания и проверка решений — но учителя не будет,
подсказки останутся только заготовленные.

Ключ ищется по порядку:

1. хранилище паролей Windows (основное место);
2. файл `.env` рядом с программой — `OPENAI_API_KEY=sk-...`;
3. если нигде нет, при запуске появится окно с просьбой ввести.

**В сборку ключ не попадает.** 

Стоит завести для приложения отдельный проект в панели OpenAI. Полное прохождение курса обходится примерно
в 3 доллара.

## Главные решения

**Занятие ведёт код, а не модель.** Последовательность уроков, переход
к следующему заданию и уровень подсказки определяются программой. Модель
объясняет и отвечает на вопросы, но не решает, чему учить дальше.

**Лестница подсказок.** Учитель никогда не выдаёт решение по своей
инициативе: сначала наводящий вопрос, потом указание на место, потом
механика на постороннем примере, и только по настойчивой просьбе —
полный разбор. Уровень сбрасывается при перезапуске: вернувшись к заданию
на следующий день, ученик снова получает вопрос, а не готовый ответ.

**Память вместо переписки.** В промпт уходит не история разговора,
а короткая выжимка: что освоено, что шатается, какие ошибки повторяются.
Около 500 токенов вместо десятков тысяч.

**Однозначное объясняется без модели.** Незакрытая скобка, забытое
двоеточие, опечатка в имени — на это отвечает локальная база из 24 правил.
Мгновенно и без сети. Но кнопка «Не понимаю» работает поверх неё всегда.

**Курс проверяется машиной, а не вычитывается.** При сборке курса
эталонное решение каждого задания прогоняется через собственные тесты,
тесты проверяются на то, что не пропускают пустышку, а каждый пример
из теории запускается. Ошибка в задании до ученика не доходит.

Проверить курс:

```
.venv\Scripts\python -m app.course.loader
```

## Сборка

```
.venv\Scripts\python tools\make_icon.py
.venv\Scripts\pyinstaller PythonLab.spec --noconfirm
```

Готовое — в `dist/PythonLab/`. Около 100 МБ: браузерный движок Qt и прочий
вес исключены.

Собирается **одной папкой, а не одним файлом**, намеренно: приложение
запускает само себя дочерним процессом на каждый запуск кода, и в режиме
одного файла каждый такой запуск распаковывал бы весь архив заново.

Прогресс ученика лежит в `data/lab.db` рядом с программой. Скопировать
папку целиком — переедет и прогресс, и память учителя.

## Курс

11 тем, 41 урок, 122 задания.

1. Первые шаги — `print`, текст, числа, чтение ошибок
2. Переменные и ввод — `input`, `int`
3. Вычисления и красивый вывод — остаток, f-строки
4. Условия — `if`, `elif`, сравнения
5. Циклы — `for`, `while`, накопитель, `break`
6. Списки — индексы, перебор, отбор, сортировка
7. Функции — параметры, `return`
8. Словари, кортежи, множества
9. Текст, `try/except`, файлы
10. Итоговый проект
11. Экзамен — четыре своих проекта

В конце каждой темы задания на всю тему и подведение итогов с оценкой.

Чего в курсе нет: модулей и `pip`, классов, списочных сборок. Это
следующий шаг.
